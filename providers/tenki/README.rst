Package ``apache-airflow-providers-tenki``

Release: ``1.0.0``


`Tenki <https://tenki.sh/>`__ sandbox executor.

Runs each Airflow task inside a dedicated, ephemeral Tenki sandbox (an isolated micro-VM)
provisioned through the Tenki sandbox SDK. The scheduler builds a workload and passes it to
the ``TenkiExecutor``, which serializes it into a Task SDK command, launches a sandbox that
runs the same Airflow code as the scheduler, and polls the sandbox until it finishes. This
gives strong per-task isolation and lets individual tasks request their own image, CPU,
memory and environment. The ``TenkiExecutor`` can co-exist with other executors (for example
``LocalExecutor`` or ``KubernetesExecutor``) in the same Airflow deployment.


Provider package
----------------

This is a provider package for ``tenki`` provider. All classes for this provider package
are in ``airflow.providers.tenki`` python package.

You can find package information and changelog for the provider
in the `documentation <https://airflow.apache.org/docs/apache-airflow-providers-tenki/1.0.0/>`_.

Installation
------------

You can install this package on top of an existing Airflow installation (see ``Requirements`` below
for the minimum Airflow version supported) via
``pip install apache-airflow-providers-tenki``

The package supports the following python versions: 3.10,3.11,3.12,3.13,3.14
